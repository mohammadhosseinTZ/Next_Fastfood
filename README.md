The purpose of this project:
<ul>
  <li>Browse and Order Fast Food Items Online</li>
  <li>View Detailed Item Information via Popup Modals</li>
  <li>Access and Manage Items in a Dedicated Cart Page</li>
</ul>  
</br>
✅ Technologies Used:
<ul>
  <li>Fast Food Ordering App built with Next.js and TypeScript</li>
  <li>Popup Item Preview using Intersection Observer and Parallel Routes</li>
  <li>Add-to-Cart Functionality with Dynamic Cart Page</li>
  <li>Cart Management and Item Quantity Update</li>
  <li>Reducer and Context to Manage datas</li>
</ul>
